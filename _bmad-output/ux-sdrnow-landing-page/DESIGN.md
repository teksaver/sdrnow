# Brand & Style
SDRnow projette une image d'efficacité, de dynamisme et de sérieux. L'univers visuel est bicolore (Blanc et Orange vibrant), sans fioritures. Il doit inspirer confiance à des décideurs B2B (Directeurs Commerciaux, CFO) tout en montrant une approche agressive sur les résultats.

# Colors
- **Primary (Brand Orange) :** `#F26522` - Utilisé pour l'action (boutons) et les zones d'attention majeures (fonds de section clés).
- **Background :** Blanc pur `#FFFFFF` pour aérer la lecture.
- **Surface :** Gris très clair `#F9FAFB` pour contraster légèrement certaines sections (ex: Pricing).
- **Text :** Gris anthracite presque noir `#111827` pour une lisibilité maximale.

# Typography
Police sans-serif moderne (Inter ou équivalent).
- Les titres sont en gras (Bold) pour marquer la structure de l'argumentaire.
- Le corps de texte est clair, avec un interlignage généreux (1.6) pour faciliter le scan visuel.

# Layout & Spacing
- Layout pleine largeur avec un conteneur central max-width (ex: 1024px) pour garder un texte facile à lire.
- Espacement de section (`80px` min) pour bien séparer la promesse, la méthode, et le pricing.

# Shapes & Elevation
- Minimaliste : on évite les ombres portées complexes (drop shadows) et les bords extrêmement arrondis.
- Les bords sont légèrement adoucis (`4px`) pour un rendu professionnel "tech/moderne", mais restent sérieux.
- Iconographie : icônes filaires (outlines) simples, blanches sur fond orange ou orange sur fond blanc.

# Components
- **Primary Button (CTA) :** Fond orange, texte blanc, bold. Un seul type de bouton sur tout le site : "Mon agenda".
- **Cards (Pricing/Méthode) :** Fond blanc ou gris clair, bordure subtile. Pas d'effet de survol (hover) gadget.

# Do's and Don'ts
- **Do :** Utiliser de grands aplats oranges pour séparer les sections (comme dans le PDF).
- **Do :** Garder le texte court et percutant.
- **Don't :** Ajouter des images d'illustration de banque d'images génériques ("business men shaking hands"). Le texte et la couleur suffisent.
- **Don't :** Utiliser d'autres couleurs d'accent (pas de vert, de bleu). Rester strictement dans l'ADN Orange/Gris/Blanc.
